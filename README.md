# Work in Progress - Flight Delay Prediction

Final project developed for the Statistics for Data Science Specialization at Pontifícia Universidade Católica de Minas Gerais.





## Dataset

The original dataset is not included in this repository due to its size (around 600 MB and 3 million records). It was downloaded on 13 june 2026 from [Kaggle](https://www.kaggle.com/datasets/patrickzel/flight-delay-and-cancellation-dataset-2019-2023/data).

A representative random sample (`data/sample_flights.csv`) generated from the original dataset is included for demonstration purposes and for running the project's automated tests.
The sample dataset can be regenerated using `scripts/create_sample.py`.
